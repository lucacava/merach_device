How to pair

With the ESP32 board (recommended): the board advertises a real smart trainer, byte-for-byte like the bike. On a Garmin Edge, remove any previous Better_Merach sensor, then Sensors → Add Sensor → Search All → Better_Merach: it shows up as a trainer and carries power, cadence, speed, distance and calories in a single sensor. Zwift finds it the same way; the board accepts up to three connections at once.

From the Mac: macOS cannot advertise the FTMS service data that identifies a trainer, so Garmin devices only list it as a power or a speed/cadence sensor, one type per device. Use the "smart trainer" profile with apps that do not need it, or the two pairing steps for a power-only or speed/cadence-only pairing.

Zwift and similar apps (on another computer or tablet — a Mac cannot see its own sensor): pick Better_Merach for Power and Cadence. Selecting it as Controllable is optional: resistance commands are acknowledged and ignored, since the knob is manual.

Sends the head unit's fields once per second, recomputed: power from the spin-down calibration, calories from the work done, speed and distance from power (flat road), resistance = knob position. Sends zero when the bike is idle or disconnected. The connector must keep running in Terminal.

Knob below 4? The bike cannot tell positions 0–4 apart: tap the one you are using and the model uses it (default 2). Above 4 the position is read automatically.
